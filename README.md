# Loan Default Risk Prediction using Explainable Machine Learning

## Overview
This project presents an interpretable machine learning framework for predicting loan default risk in financial systems using Logistic Regression, Random Forest, and XGBoost models.

The project integrates Explainable AI (XAI) techniques using SHAP to improve transparency and interpretability in financial decision-making.

---

## Features
- Data preprocessing and cleaning
- Handling missing values
- SMOTE-based class balancing
- Feature scaling and encoding
- Machine Learning model training
- XGBoost-based prediction
- ROC Curve analysis
- SHAP Explainability
- Feature importance visualization

---

## Technologies Used
- Python
- Scikit-learn
- XGBoost
- SHAP
- Pandas
- NumPy
- Matplotlib

---

## Machine Learning Models
1. Logistic Regression
2. Random Forest
3. XGBoost

---

## Results
XGBoost achieved the best performance for loan default prediction with strong classification accuracy and interpretability.
